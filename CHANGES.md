# Изменения в редакторе требований и бонусов

## Обзор

Добавлены следующие улучшения в редактор требований/бонусов (requirements/bonuses editor):

### 1. Замена select на кнопки для action
**Файл:** `js/reqbon.js`

- Создана новая функция `createActionButtons()` для создания группы кнопок вместо select'а
- Добавлены 4 иконки для операций сравнения:
  - `=` (equal)
  - `≠` (not_equal)
  - `>` (more / greater than)
  - `<` (less / less than)
- Каждая кнопка имеет класс `action-button` и атрибут `data-value` для идентификации
- Выбранная кнопка получает класс `active`
- Значение сохраняется в скрытый input с классом `action-value`

### 2. Добавлены прослушиватели на изменения полей
**Файл:** `js/events/events-main.js`

Внутри функции `updateValueField()` добавлены event listeners для отслеживания изменений:

#### Поля с прослушивателями:
- **subType** - срабатывает при изменении (change и input события)
- **action** - срабатывает при клике на кнопку
- **value** - срабатывает при изменении (change и input события)
- **duration** - срабатывает при изменении (change и input события)

#### Обработчик: `onRequirementFieldChange(fieldName, value)`
- Логирует все изменения в консоль
- Может быть расширен для сохранения изменений в реальном времени
- Вызывается сразу при изменении значения

### 3. Обновление функции сохранения
**Файл:** `js/events/events-main.js` в методе `saveButton.onclick`

- Обновлена логика получения значения `action` из кнопок вместо select'а
- Сначала ищет активную кнопку с классом `action-button.active`
- Если найдена, использует её `data-value`
- Fallback на скрытый input если кнопка не найдена

### 4. Обновление функции редактирования
**Файл:** `js/events/events-main.js` в обработчике `list.onclick`

- Исправлена установка значений при редактировании существующего требования
- Для action: находит кнопку по `data-value` и активирует её
- Также обновляет скрытый input значение

### 5. Добавлены CSS стили
**Файл:** `css/style.css`

```css
.action-buttons-group - контейнер для кнопок (flex, gap 8px)
.action-button - стиль кнопки (40x40px, border, transition)
.action-button:hover - при наведении (изменение цвета border'а)
.action-button.active - активная кнопка (синий фон, белый текст, тень)
.action-button:active - при клике (уменьшение на 5%)
.action-value - скрытый input для хранения значения
```

## Технические детали

### Как работают кнопки action:
1. Функция `createActionButtons()` создает контейнер div с классом `action-buttons-group`
2. Для каждого типа action (equal, not_equal, more, less) создается кнопка
3. При клике кнопка получает класс `active`, остальные теряют
4. Значение синхронизируется в скрытый input для совместимости с существующим кодом
5. При сохранении сначала проверяется активная кнопка, затем скрытый input

### Event listeners:
- Используется `addEventListener` для change и input событий
- Для action используются click события на кнопках
- Все listeners вызывают `this.onRequirementFieldChange()`
- Listeners добавляются в функции `renderSection()` сразу после создания элемента

### Сохранение изменений:
- Текущая реализация логирует изменения в консоль
- Метод `onRequirementFieldChange()` может быть расширен для:
  - Обновления превью
  - Сохранения в localStorage
  - Синхронизации с JSON данными
  - Отправки на сервер

## Использование

В редакторе требований/бонусов при выборе типа требования, вместо select'а для action отобразятся четыре кнопки с символами:
- Нажмите нужную кнопку чтобы выбрать операцию
- Выбранная кнопка будет подсвечена синим цветом
- При редактировании существующего требования кнопка автоматически вернет выбранное значение

## Совместимость

- Все изменения обратно совместимы
- Работает со всеми типами требований
- Не влияет на бонусы (у них нет action)
- Скрытый input обеспечивает fallback совместимость
